# Glossary — Daftar Istilah & Akronim

**Summary**: Daftar istilah dan akronim yang sering muncul di seluruh wiki Inspektorat II. Fungsi utama: mempercepat pembaca baru memahami konteks dan mencegah ambiguitas antar halaman.

**Sources**: Sintesis dari seluruh halaman wiki existing (internal).

**Last updated**: 2026-04-24

---

## A – C

| Istilah | Kepanjangan / Makna |
|---|---|
| **Adendum** | Perubahan resmi atas kontrak yang sudah ditandatangani, biasanya untuk penyesuaian harga, waktu, atau ruang lingkup. Lihat [[lhr-server-crawling-2025]] untuk kasus adendum ganda nomor sama. |
| **APIP** | Aparat Pengawasan Intern Pemerintah — payung hukum bagi Itjen K/L dan Inspektorat Daerah. |
| **Aptika** | Direktorat Jenderal Aplikasi Informatika (unit nomenklatur lama Kominfo, sebagian fungsinya sekarang di bawah Ditjen Ekosistem Digital dan Ditjen Wasdig). Lihat [[lhr-kontrak-aptika-2025]]. |
| **AT** | Anggota Tim (audit). |
| **BAHP** | Berita Acara Hasil Pemilihan — dokumen hasil evaluasi pemilihan penyedia. |
| **BAST** | Berita Acara Serah Terima — dokumen konfirmasi pekerjaan/barang telah diterima; krusial sebagai dasar pembayaran. |
| **BMN** | Barang Milik Negara. |
| **BPK** | Badan Pemeriksa Keuangan — pemeriksa eksternal, merujuk ke UUD 45. |
| **BPKP** | Badan Pengawasan Keuangan dan Pembangunan — auditor internal pemerintah. |
| **BUN** | Bendahara Umum Negara (BA BUN = Bagian Anggaran BUN, tempat anggaran K/L tertentu dianggarkan). |
| **CaLK** | Catatan atas Laporan Keuangan. |
| **CBA** | Cost-Benefit Analysis. |
| **CNS** | Content Negative System (padanan CSE untuk konten tertentu di Wasdig — *perlu verifikasi definisi*). |
| **CSE** | Content Security Engine — sistem pendukung pemutusan akses/takedown konten negatif di Ditjen Wasdig. Lihat [[lhr-server-crawling-2025]]. |
| **CHR** | Catatan Hasil Reviu — bentuk output reviu yang lebih singkat dari LHR. |

## D – I

| Istilah | Kepanjangan / Makna |
|---|---|
| **Dalnis** | Pengendali Teknis (peran dalam tim audit, antara KT dan Inspektur). |
| **DBS** | Digital Broadcasting System — sarpras broadcasting eks-Kominfo; sedang dalam proses alih status ke LPP TVRI. Lihat [[isu-dbs]]. |
| **Ditjen** | Direktorat Jenderal (eselon I). |
| **DIPA** | Daftar Isian Pelaksanaan Anggaran — dokumen dasar pelaksanaan anggaran K/L. |
| **DJED** | Singkatan informal untuk Ditjen Ekosistem Digital. |
| **Ekosistem Digital** | Ditjen Pengembangan Ekosistem Digital (mitra Inspektorat II). Lihat [[peta-risiko-ekosistem-digital-2026]]. |
| **Exit meeting** | Pertemuan penutup audit untuk menyampaikan temuan sebelum final. |
| **FGD** | Focus Group Discussion. |
| **HPS** | Harga Perkiraan Sendiri — acuan harga dalam pengadaan. |
| **IGDX** | Indonesia Game Developer Exchange (event industri gim). |
| **IGRS** | Indonesia Game Rating System — sistem klasifikasi gim Indonesia; diluncurkan 4 April 2026 dan menjadi objek audit aktif. Lihat [[igrs]]. |
| **IKU / IKSP** | Indikator Kinerja Utama / Indikator Kinerja Sasaran Program. |
| **Inspektorat II** | Unit pengawas internal Kemkomdigi, mitra Ditjen Wasdig & Ditjen Ekosistem Digital. Lihat [[inspektorat-ii]]. |
| **Irjen** | Inspektur Jenderal. |
| **Itjen** | Inspektorat Jenderal. |

| **NWS** | *(placeholder — perlu verifikasi bila muncul di dokumen)* |

| **PJT** | Penyedia Jasa Telekomunikasi (dalam konteks TKPPSE = vendor jalur/transit). |
| **PKPT** | Program Kerja Pengawasan Tahunan. |
| **PKA** | Program Kerja Audit. |
| **PM** | *(konteks: Penilaian Mandiri, dalam konteks SPIP/ZI)* |
| **Permenkominfo / PermenPANRB** | Peraturan Menteri Komunikasi dan Informatika / Peraturan Menteri PAN-RB. |
| **PSE** | Penyelenggara Sistem Elektronik. |
| **PSO** | Public Service Obligation (mis. PSO POS). |
| **PSrE** | Penyelenggara Sertifikat Elektronik (termasuk PSrE Induk — Root CA nasional). |
| **PJP** | Penanggung Jawab Pengawasan (peran struktural di tim audit). |
| **PNBP** | Penerimaan Negara Bukan Pajak. |

## Catatan

- Istilah yang diberi tanda *(perlu verifikasi)* belum terkonfirmasi penuh dari dokumen sumber; mohon auditor memperbaiki saat informasi tersedia.
- Tambahkan entri baru ketika muncul akronim baru di LHP/penugasan — konsisten pakai format yang sama.
