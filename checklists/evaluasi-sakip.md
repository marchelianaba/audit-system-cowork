**Timing:** Setelah tahun anggaran (Januari–Maret) untuk ex-post; atau triwulanan untuk on-going

## Aturan Validasi

```
KRITIS:
  → W1 (Surat Tugas)
  → W2 (Renstra) — tanpa ini komponen Perencanaan tidak dapat dinilai
  → W3 (PK) — tanpa ini komponen Pengukuran tidak dapat dinilai

PERINGATAN per komponen (nilai komponen = 0 atau minimal jika dokumen tidak ada):
  → W4 tidak ada → komponen Pelaporan Kinerja tidak dapat dinilai (15 poin)
  → P2 tidak ada → sub-komponen pengukuran tidak dapat dinilai
  → P4 tidak ada → komponen Evaluasi Internal tidak dapat dinilai (10 poin)
  → P5 tidak ada → komponen Capaian Kinerja tidak dapat dinilai (20 poin)

INFORMASI:
  → O1–O5 tidak ada → evaluasi tetap berjalan dengan keterbatasan yang dicatat
```
