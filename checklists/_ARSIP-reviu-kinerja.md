# Checklist Dokumen — Reviu Laporan Kinerja (LKj/SAKIP)

**Skill:** reviu-kinerja
**Lingkup:** Kualitas penyajian LKj — 3 aspek: Format, Mekanisme Penyusunan, Substansi (23 kriteria PermenPAN-RB 53/2014)
**Timing:** Sebelum LKj diserahkan ke KemenPAN-RB (biasanya Februari)

---

## Dokumen WAJIB

| No | Dokumen | Sumber/Folder | Keterangan |
|----|---------|---------------|------------|
| W1 | Surat Tugas (ST) | `00-surat-tugas/` | Dasar penugasan |
| W2 | Laporan Kinerja (LKj) yang akan direviu | `04-pelaksanaan/` atau `00-surat-tugas/` | Dokumen utama — bisa dikirim via chat |
| W3 | Perjanjian Kinerja (PK) tahun yang sama | `03-perencanaan/` atau via chat | Dasar pengujian kesesuaian target |

---

## Dokumen PENTING (reviu terbatas jika tidak ada)

| No | Dokumen | Sumber | Dampak jika tidak ada |
|----|---------|--------|-----------------------|
| P1 | Renstra unit kerja yang berlaku | `03-perencanaan/` | Keselarasan PK ↔ Renstra tidak dapat diverifikasi |
| P2 | Laporan Pemantauan (B01–B12 / triwulanan) | `04-pelaksanaan/` | Aspek mekanisme penyusunan tidak dapat dinilai sepenuhnya |
| P3 | SK/Surat Tim Penyusun LKj | `01-peraturan-internal/` | Pertanggungjawaban penyusunan tidak dapat dikonfirmasi |
| P4 | Data dukung IKU (dokumen evidensi per indikator) | via chat atau `04-pelaksanaan/` | Keandalan data kinerja tidak dapat diverifikasi |

---

## Dokumen OPSIONAL

| No | Dokumen | Manfaat |
|----|---------|---------|
| O1 | SOP Penyusunan LKj | Mengonfirmasi mekanisme penyusunan |
| O2 | LKj tahun sebelumnya | Perbandingan tren kinerja |
| O3 | IKU yang sudah ditetapkan | Memperkuat pengujian substansi |
| O4 | ND Permintaan Reviu | Konteks dan fokus yang diminta pimpinan |

---

## Aturan Validasi

```
KRITIS:
  → W1 (Surat Tugas)
  → W2 (LKj yang akan direviu)

PERINGATAN:
  → W3 (PK) tidak ada → substansi kriteria 1-6 tidak dapat dinilai
  → P4 tidak ada → keandalan data kinerja dicatat sebagai "tidak dapat diverifikasi"

INFORMASI:
  → P1, P2, P3, O1–O4 tidak ada → reviu tetap berjalan dengan catatan keterbatasan
```

---

## Pesan Notifikasi

Jika W2 (LKj) tidak ada:
> ❌ **Reviu tidak dapat dimulai.** Dokumen Laporan Kinerja (LKj) yang akan direviu tidak ditemukan. Mohon upload dokumen LKj atau kirim via chat.

Jika W3 (PK) tidak ada:
> ⚠️ **Perjanjian Kinerja (PK) tidak ditemukan.** Aspek Substansi (khususnya kesesuaian tujuan/sasaran dengan PK) tidak dapat dinilai. Reviu akan dilanjutkan untuk aspek Format dan Mekanisme. Ketik **LANJUT** atau upload PK terlebih dahulu.

Jika dokumen lengkap:
> ✅ **Dokumen siap.** Ketik **LANJUT** untuk memulai reviu.
