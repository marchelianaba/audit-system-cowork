# Checklist Dokumen — Evaluasi Internal Reformasi Birokrasi

**Skill:** evaluasi-reformasi-birokrasi
**Lingkup:** Evaluasi Internal RB oleh APIP — Ex-Ante (telaah Roadmap/Rencana Aksi) dan On-Going (monitoring pelaksanaan triwulanan)
**Dasar Hukum:** PermenPAN-RB 9/2023, KepmenPAN-RB 182/2024, SE MenPAN-RB 6/2025
**Catatan:** Evaluasi RB tidak menggunakan KKP tabel konvensional — output adalah LHEI (Laporan Hasil Evaluasi Internal) berupa Nota Dinas + Laporan. Lembar Kerja Evaluasi per dimensi diisi sebagai lampiran.

## Aturan Validasi

```
KRITIS (evaluasi TIDAK DAPAT dilanjutkan):
  → W1 (Surat Tugas)
  → Salah satu dari W2 atau W3 harus ada — tanpa ini tidak ada objek telaah

  Khusus On-Going:
  → W4 (laporan capaian TW) juga KRITIS — tanpa data realisasi,
    penilaian 4 dimensi on-going tidak dapat dilakukan

PERINGATAN — dimensi tidak dapat dinilai:
  → W5 tidak ada → gambaran proses pelaksanaan tidak dapat dikonfirmasi
  → P1 tidak ada → dimensi Ketepatan Pelaksanaan tidak dapat dinilai
  → P2 tidak ada → dimensi Ketercapaian Output hanya berdasarkan klaim laporan
  → P3 tidak ada → dimensi Kualitas Pelaksanaan tidak dapat dinilai
  → P4 tidak ada → dimensi Kesesuaian Waktu tidak dapat diukur secara akurat

INFORMASI (catat, lanjutkan):
  → O1–O5 tidak ada → evaluasi tetap berjalan dengan dokumen yang tersedia
```

## Pesan Notifikasi untuk Auditor

Jika Rencana Aksi (W3) tidak ada:
> ❌ **Evaluasi tidak dapat dimulai.** Rencana Aksi RB tahun berjalan tidak ditemukan. Rencana Aksi adalah objek utama telaah (Ex-Ante) dan monitoring (On-Going). Mohon upload dokumen Rencana Aksi, kemudian ketik **ULANG**.

Jika W4 (laporan capaian TW) tidak ada untuk evaluasi On-Going:
> ❌ **Data realisasi tidak tersedia.** Evaluasi On-Going memerlukan laporan capaian Rencana Aksi untuk triwulan yang dievaluasi. Tanpa data ini, 4 dimensi penilaian (Ketepatan, Output, Kualitas, Waktu) tidak dapat dinilai. Mohon upload laporan capaian TW [X], kemudian ketik **ULANG**.

Jika dokumen dimensi sebagian tidak ada:
> ⚠️ **Beberapa dimensi tidak dapat dinilai secara penuh.** Dokumen pendukung untuk dimensi berikut tidak tersedia: [daftar]. Penilaian dimensi tersebut akan menggunakan data dari laporan capaian dengan catatan keterbatasan. Ketik **LANJUT** untuk melanjutkan atau upload dokumen tambahan.

Jika dokumen lengkap:
> ✅ **Dokumen siap.** Rencana Aksi dan laporan capaian tersedia. Ketik **LANJUT** untuk memulai evaluasi.
