# Checklist Dokumen — Audit Kinerja Program Prioritas

**Skill:** audit-kinerja
**Lingkup:** Efektivitas, efisiensi, dan ekonomisitas program — dari input hingga dampak
**Audit kinerja menuntut bukti yang cukup dan kompeten untuk menyimpulkan pencapaian program**

---

## Dokumen WAJIB

| No | Dokumen | Sumber/Folder | Keterangan |
|----|---------|---------------|------------|
| W1 | Surat Tugas (ST) | `00-surat-tugas/` | Dasar penugasan + scope program yang diaudit |
| W2 | Dokumen desain program (TOR/KAK program) | `03-perencanaan/` | Tujuan, target, sasaran, logika intervensi program |
| W3 | Perjanjian Kinerja (PK) + target IKU program | `03-perencanaan/` | Ukuran keberhasilan yang akan diuji |
| W4 | Data realisasi/capaian program | `04-pelaksanaan/` | Bukti pencapaian — laporan kinerja, realisasi output |

---

## Dokumen PENTING (audit terbatas jika tidak ada)

| No | Dokumen | Sumber | Dampak jika tidak ada |
|----|---------|--------|-----------------------|
| P1 | DIPA/RKA yang terkait program | `03-perencanaan/` + `05-keuangan/` | Dimensi Ekonomis tidak dapat diaudit |
| P2 | Laporan realisasi anggaran program | `05-keuangan/` | Efisiensi biaya per output tidak dapat dihitung |
| P3 | SP2D / bukti realisasi keuangan | `05-keuangan/` | Verifikasi serapan anggaran tidak dapat dilakukan |
| P4 | Data dukung capaian IKU (evidensi per indikator) | `04-pelaksanaan/` | Keandalan data kinerja tidak dapat dikonfirmasi |
| P5 | Laporan supervisi/monitoring program | `04-pelaksanaan/` | Proses pelaksanaan tidak dapat dianalisis |
| P6 | Kontrak/SPK kegiatan yang terkait program | `02-kontrak/` | Output vs kontrak tidak dapat diverifikasi |

---

## Dokumen OPSIONAL (memperkuat analisis kausalitas)

| No | Dokumen | Manfaat |
|----|---------|---------|
| O1 | Laporan evaluasi program oleh unit kerja sendiri | Perbandingan dengan penilaian internal |
| O2 | Dokumen baseline (kondisi sebelum program) | Pengukuran dampak bersih program |
| O3 | Laporan audit/evaluasi tahun sebelumnya | Riwayat temuan dan tindak lanjut |
| O4 | Regulasi/kebijakan yang menjadi dasar program | Memperkuat kriteria pengujian |
| O5 | Data eksternal/BPS/lembaga independen | Verifikasi dampak dari sumber luar |

---

## Aturan Validasi

```
KRITIS:
  → W1 (Surat Tugas)
  → W2 (Desain program/TOR) ATAU W3 (PK + target IKU)
    → Tanpa ini tidak ada kriteria pengujian yang jelas

PERINGATAN — dimensi audit tidak dapat dinilai:
  → W4 tidak ada → efektivitas tidak dapat disimpulkan — KETERBATASAN MATERIAL
  → P1 + P2 tidak ada → efisiensi biaya tidak dapat dihitung
  → P3 tidak ada → serapan anggaran tidak dapat diverifikasi
  → P4 tidak ada → keandalan data capaian diragukan — tandai sebagai keterbatasan

INFORMASI:
  → O1–O5 tidak ada → audit tetap berjalan dengan bukti yang tersedia
```

---

## Pesan Notifikasi

Jika dokumen desain program tidak ada sama sekali:
> ❌ **Audit tidak dapat dimulai tanpa kriteria pengujian.** Tidak ditemukan dokumen yang mendefinisikan tujuan, target, dan indikator program (TOR/KAK atau PK). Mohon upload minimal salah satunya.

Jika data capaian (W4) tidak ada:
> ⚠️ **Data realisasi capaian program tidak ditemukan.** Audit Efektivitas tidak dapat dilakukan tanpa data ini. Audit masih dapat menilai kualitas desain program dan kelayakan target. Ketik **LANJUT** untuk melanjutkan dengan keterbatasan, atau upload data capaian terlebih dahulu.

Jika dokumen inti tersedia:
> ✅ **Dokumen inti tersedia.** Ketik **LANJUT** untuk memulai audit kinerja.
